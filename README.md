## ✨ Funcionalidades

- 🎨 Interface colorida e formatada com Rich
- ⌨️ Comandos simples e diretos
- 🧩 Ambiente isolado com ambiente virtual (venv)

## 🚀 Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/ItzYago/CLI.git
cd CLI
```

### 2. Crie e ative o ambiente virtual

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

> Se ainda não existir, crie o arquivo com `pip freeze > requirements.txt` ou adicione manualmente `rich`.

## ▶️ Como usar

Com o venv ativado, execute:

```bash
python main.py
```

```bash
Para obter a senha se usuário, entre na pasta Terminal/conta e veja a senha de "castro"
```

## 🛠️ Comandos

| Comando   | Descrição                                      |
|-----------|------------------------------------------------|
| `help`    | Mostra a lista de comandos disponíveis         |
| `version` | Exibe a versão atual do programa               |
| `about`   | Mostra informações sobre o projeto             |
| `exit`    | Encerra o terminal                             |
